# Remota 管理台交互规范

管理台提供临时设备、AI 连接、接入凭据和 MCP 凭据管理。页面通过同源接口读取快照并提交管理操作，交互状态只属于当前浏览器登录。

接口和权限见 [管理员通道](../contracts/admin.md)，统计窗口见 [运行默认值](../contracts/README.md#运行默认值)，修改结果的核对规则见 [修改与结果核对](../contracts/admin.md#修改与结果核对)。

## 快照与列表

页面在可见且已登录时每 5 秒刷新一次快照，同一时刻最多一次刷新；隐藏时暂停，返回前台可刷新。失败保留旧数据并标出最近成功时间和未更新状态，不能把旧快照当作新授权。

summary 使用完整快照计数，不随前端搜索或筛选变化。备注提交发生 REVISION_CONFLICT 时，界面保留草稿并让操作者核对，禁止覆盖未提交输入。核对完成前不允许采用修订；后续自动或手动刷新成功时，界面同步更新核对状态。

设备搜索为大小写无关的普通子串，可搜索会话 ID、主机名、备注、OS/架构及关联凭据名称或 ID；不执行正则，不搜索秘密或命令。凭据筛选为全部、有效、即将到期、已过期、已撤销。搜索和筛选只在本次页面内存保存。

到期提醒采用通用运行默认值中的 expiring_credentials、expiring_sessions 统计窗口。显示基于最近快照和浏览器经过时间的估算，过期观察、匹配数、全量数量分开；授权由两端检查。

## 身份与秘密

登录、退出和身份失效切换浏览器认证代际。旧请求、旧 CSRF、旧创建结果和剪贴板回调不能更新后续登录的界面。退出清除列表、筛选、备注与凭据草稿、弹窗和一次性秘密；只隐藏 DOM 不算清除。

退出接口返回 401 时，浏览器仍清除本地状态。网络失败时明确提示未取得服务端注销确认，不把本地清理显示为服务端会话已经撤销。

CSRF 和秘密只保留在当前页内存，不写入 localStorage、URL 或日志。一次性秘密只在当前有效操作的弹窗展示，关闭、退出、身份失效或页面销毁时清除。

秘密默认掩码显示，由操作者显式显示或复制；复制失败时提供可选择的完整文本，关闭后不提供再次查看入口。轮换和撤销前展示关联影响，并由操作者明确确认。

远端名称、备注和其他文本按不可信数据使用纯文本展示。退出后旧签发响应不得显示秘密或改变新登录状态。

## 接入与展示

接入指引从 public_url 构造示例，不包含真实秘密；缺少配置则提示配置。设备接入示例省略 token，使用隐藏输入；MCP 示例使用 MCP_TOKEN 占位符。复制完整 ses ID 不发请求、不选择目标或改变授权；失败提供可选中的完整文本。

传输观察分别显示浏览器协议、服务配置和后端最后一段连接；不把代理终止 TLS 或任一端可达扩大为全链路验证。

中文和英文切换保留输入、焦点、弹窗及当前一次性秘密，不发业务修改请求。仅语言偏好可写入浏览器存储，存储不可用仍可切换。远端名称、备注、命令、标识和版本不翻译。
